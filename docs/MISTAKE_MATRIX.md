# Матрица на грешки — Часови / Полагање × Полигон / Градска

Генерирано од `src/game/rules/matrix.ts` (регистар 2026-11-18.2, проверено 2026-11-18). Не уредувај рачно — `npm run matrix`.

Три работи се држат одвоено: **сообраќаен закон** (ЗБСП), **официјални критериуми на испитот** (Образец бр. 1 и бр. 4, Правилник Сл. весник 29/2025) и **дополнителни игровни казни**.

- Праг: над **50** негативни поени = не положено (полигон: потврдено, чл. 36 ст. 2; градска: иста вредност, **за проверка од инструктор**).
- Ставка вредна повеќе од прагот сама по себе = испитот завршува (`examEndOnCritical: true`, практиката на испитувачот е **за проверка**).
- Часови никогаш не носат официјални поени; влијаат само на резултатот од часот.
- Извори: [ЗБСП — редакциски пречистен текст (до Сл. весник на РСМ 193/25)](https://portal.mdt.gov.mk/post-body-files/zakoni-mvr-file-jL7k.pdf) · [Правилник за начинот на спроведување на возачките испити (Сл. весник на РСМ 29/2025)](https://portal.mdt.gov.mk/post-body-files/podzakonski-akti-mvr-file-T7nu.pdf) · [МВР — Прирачник за полагање возачки испит](https://portal.mdt.gov.mk/post-body-files/polaganje-vozacki-ispit-file-PfGR.pdf)
